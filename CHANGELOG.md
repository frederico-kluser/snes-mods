# Changelog

Todas as mudanças relevantes do **snes-mods** ficam registradas aqui.

O formato segue o [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e o projeto adota o
[Versionamento Semântico](https://semver.org/lang/pt-BR/).

- As entradas são **geradas** a partir dos [Conventional Commits](https://www.conventionalcommits.org/)
  pelo release-please (`.github/workflows/release-please.yml`) — não edite à mão.
- As versões são publicadas como tags `vX.Y.Z` a partir da `main`.
